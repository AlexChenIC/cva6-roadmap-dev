# RV32 configuration

## Summary

A 32-bit CVA6 build profile for embedded and area-sensitive systems. It keeps the CVA6 architecture usable where RV64 is more than the product needs.

## Description

The RV32 configuration preserves the CVA6 implementation style while targeting smaller address spaces and embedded integration constraints.

## User value

Lets teams reuse CVA6 in smaller products without adopting a full 64-bit platform.
