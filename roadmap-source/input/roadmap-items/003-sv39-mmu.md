# Sv39 MMU & virtual memory

## Summary

Sv39 virtual memory support for Linux-class systems and process isolation. It anchors CVA6 as a practical application processor core.

## Description

The Sv39 MMU capability supports page-based address translation, privilege separation, and the operating-system features expected by RISC-V application profiles.

## User value

Enables standard OS ports and memory protection for application workloads.
