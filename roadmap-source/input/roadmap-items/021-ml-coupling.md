# ML accelerator coupling

## Summary

Exploratory coupling patterns for machine-learning accelerators next to CVA6. The work focuses on clean interfaces and software handoff rather than a specific accelerator block.

## Description

This idea evaluates how CVA6 could orchestrate ML accelerators through memory, interrupt, and coprocessor integration models while keeping the CPU roadmap focused.

## User value

Helps AI-oriented integrators understand how CVA6 might sit beside domain-specific compute.
