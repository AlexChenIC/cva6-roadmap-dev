# RV64GC application core

## Summary

Mature 6-stage, single-issue, in-order RV64GC core capable of booting Linux. This is the baseline application-class configuration most integrators start from.

## Description

The RV64GC configuration provides the main Linux-capable CVA6 profile, combining integer, compressed, multiply/divide, atomic, and floating-point capabilities in a proven in-order pipeline.

## User value

Gives SoC teams a stable, open application-class RISC-V core for real software bring-up.
