# ISO 26262 safety collateral

## Summary

Planned collateral package to support ISO 26262-oriented evaluation of CVA6. The scope is documentation, traceability, and verification evidence, not certification by the website.

## Description

The safety collateral track organizes the artifacts integrators need when assessing CVA6 for automotive or other functional-safety programs.

## User value

Helps safety-focused adopters understand what evidence exists and what remains to be produced.
