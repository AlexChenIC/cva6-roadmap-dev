# AXI memory subsystem & caches

## Summary

AXI-based memory interfaces and cache hierarchy for practical SoC integration. This provides the connective tissue between CVA6 and system-level fabrics.

## Description

The memory subsystem gives CVA6 a reusable path into AXI-based SoCs, including cache behavior and integration points expected by platform teams.

## User value

Reduces integration effort for teams building CVA6-based chips or FPGA prototypes.
