# core-v-verif verification environment

## Summary

Open UVM-based verification flow with passing regression for CVA6. It provides a shared baseline for community confidence and release readiness.

## Description

The core-v-verif environment captures reusable verification infrastructure, tests, and regressions that help contributors validate CVA6 changes consistently.

## User value

Gives adopters a transparent signal that released capabilities are tested in the open.
