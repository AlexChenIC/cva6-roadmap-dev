# Hypervisor extension (H)

## Summary

Released RISC-V Hypervisor extension support for CVA6, recorded from the real CVA6 5.1.0 upstream release.

## Description

Hypervisor support adds architectural state and privilege behavior needed to run virtualized guests. Partner needs now track validation, evidence, and platform-readiness work on top of the released implementation.

## User value

Opens CVA6 to virtualized embedded and edge platforms with stronger software isolation.
