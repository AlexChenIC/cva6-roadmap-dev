# HPDcache integration and performance evaluation

## Summary

Active UniBo-related performance roadmap signal around CVA6 and OpenHW HPDcache integration, evaluation, and documentation for higher-throughput memory-subsystem configurations.

## Description

OpenHW's HPDcache repository states that HPDcache is integrated with CVA6 and selected through CVA6 configuration. Public CVA6S+ material from University of Bologna researchers also evaluates CVA6 with OpenHW HPDcache as part of a higher-throughput memory architecture. This roadmap item keeps that work visible as an integration/evaluation direction, not as an unreviewed upstream delivery commitment.

## User value

Helps partners discuss CVA6 performance paths with concrete cache-system references instead of treating memory-subsystem work as an unspecified future idea.
