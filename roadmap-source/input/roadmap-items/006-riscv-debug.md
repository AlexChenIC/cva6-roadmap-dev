# RISC-V external debug

## Summary

External debug support for bring-up, firmware development, and lab diagnosis. It helps developers inspect CVA6 systems with standard RISC-V debug flows.

## Description

The released debug capability provides the hooks needed for breakpoints, inspection, and tool-driven development during hardware and software bring-up.

## User value

Makes CVA6 easier to integrate, debug, and support in real boards.
