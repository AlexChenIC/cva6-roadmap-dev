# Performance-model-guided CVA6 exploration

## Summary

Exploratory roadmap signal based on public Thales work using a CVA6 performance model to study superscalar and dual-issue design choices before RTL changes.

## Description

The public article describes performance modeling as a way to evaluate CVA6 microarchitectural changes before implementation. The roadmap keeps this as an exploratory item so it can support discussion without implying that a specific superscalar configuration has been accepted into upstream CVA6.

## User value

Creates a realistic discussion point for performance-oriented roadmap ideas while keeping implementation scope and upstream acceptance separate.
