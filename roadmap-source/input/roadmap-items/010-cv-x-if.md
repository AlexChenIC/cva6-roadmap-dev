# CV-X-IF coprocessor interface

## Summary

Released CV-X-IF 1.0.0 coprocessor interface support for CVA6, with additional superscalar configuration coverage in the CVA6 5.3.0 release line.

## Description

CV-X-IF support gives integrators a structured path to connect custom execution resources while preserving the maintainability of the upstream CVA6 core. Future accelerator ideas are tracked separately as partner needs or exploratory roadmap items.

## User value

Lets projects add specialized compute while staying aligned with the shared CVA6 roadmap.
