# Trusted execution / enclave

## Summary

Exploratory trusted-execution support for isolating sensitive workloads. The item is intentionally early-stage and will need threat-model alignment before design work.

## Description

The enclave track considers the architectural, memory-protection, and lifecycle pieces needed to support trusted execution on a CVA6-based platform.

## User value

Gives security stakeholders a visible place to shape isolation requirements before commitment.
