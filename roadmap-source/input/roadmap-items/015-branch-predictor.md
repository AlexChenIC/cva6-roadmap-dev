# Advanced branch prediction

## Summary

Planned branch prediction improvements for higher instruction throughput on control-heavy workloads. The work is expected to balance performance with area cost.

## Description

This item explores predictor structures and integration trade-offs that could improve CVA6 performance without undermining its maintainable in-order design.

## User value

Can improve real application performance while preserving the core's open, understandable structure.
