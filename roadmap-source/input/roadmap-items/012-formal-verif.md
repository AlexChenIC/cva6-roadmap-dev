# CVA6-CHERI verification scoping

## Summary

Scoping item for CVA6-CHERI verification evidence, grounded in public lowRISC, Capabilities Limited, and COSMIC material rather than an upstream CVA6 commitment.

## Description

Public COSMIC and CHERI CVA6 material describe work toward stronger verification and silicon-ready evidence for CVA6-CHERI. The roadmap keeps that signal visible as an ecosystem-facing research/evidence item, while requiring separate maintainer review before any upstream CVA6 scope is accepted.

## User value

Helps maintainers and partners discuss memory-safety verification using concrete public references instead of broad, unattributed formal-verification claims.
