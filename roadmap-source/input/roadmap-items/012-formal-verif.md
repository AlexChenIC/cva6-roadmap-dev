# Formal verification of control path

## Summary

Formal verification campaign for key CVA6 control-path behavior. It complements simulation regressions with stronger proofs around critical state transitions.

## Description

The effort targets properties where formal methods can catch corner cases that are hard to reach through directed or random simulation alone.

## User value

Increases confidence in safety- and security-relevant control behavior before release.
