# IEEE FPU (F/D)

## Summary

Single- and double-precision IEEE floating-point support for compute and control workloads. The capability is part of the released CVA6 application profile.

## Description

The F/D floating-point unit gives CVA6 software compatibility with common RISC-V numeric workloads, toolchains, and benchmark suites.

## User value

Broadens CVA6 to numeric software without requiring external acceleration.
