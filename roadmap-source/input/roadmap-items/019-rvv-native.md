# Native RVV vector unit

## Summary

Exploratory native RISC-V Vector support inside the CVA6 core. This is a larger architectural option than accelerator coupling and needs careful cost-benefit analysis.

## Description

A native RVV unit could improve vector workload performance, but it also affects pipeline complexity, verification scope, and software compatibility commitments.

## User value

Signals a possible long-term path for compute-heavy CVA6 deployments.
