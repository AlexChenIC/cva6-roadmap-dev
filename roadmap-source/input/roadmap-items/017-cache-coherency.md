# Multi-core cache coherency

## Summary

Planned exploration of coherent multi-core CVA6 configurations. It targets the system architecture needed for shared-memory multi-core products.

## Description

This work will define coherency expectations, integration boundaries, and verification needs before the roadmap commits to a concrete implementation.

## User value

Shows a path toward CVA6 platforms that need more than one application-class core.
