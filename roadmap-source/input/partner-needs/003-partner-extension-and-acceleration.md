# Clean extension points for accelerators

## Summary

Research and product teams want a maintained way to connect domain-specific accelerators without fragmenting the core roadmap.

## Requested capabilities

- CV-X-IF integration guidance
- accelerator verification strategy
- software-visible semantics for coupled compute blocks

## Public notes

Useful as a partner signal for future feature prioritization; not all accelerator ideas should become native CVA6 core features.
