# Safety evaluation evidence and traceability

## Summary

Safety-focused adopters need a reviewed evidence path that connects requirements, verification artifacts, release scope, and known limitations without presenting the website as a certification claim.

## Requested capabilities

- requirements-to-verification traceability for selected CVA6 configurations
- issue-linked evidence for open safety-relevant limitations and resolved defects
- public description of verification assumptions, coverage boundaries, and release scope
- wording that separates evaluation evidence from ISO 26262 certification claims

## Public notes

This is deliberately framed as evaluation support. Any certification language must come from a separate approved safety program, not from this portal.
