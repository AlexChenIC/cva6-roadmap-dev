# CVA6 5.1.0

## Summary

Real upstream CVA6 release adding the RISC-V Hypervisor extension, MMU refactoring, FPGA bitstream target support, and lint integration.

## Highlights

- Added the RISC-V Hypervisor extension.
- Refactored the MMU together with H-extension work.
- Added FPGA bitstream target support and a new MMU-enabled target.
- Integrated SpyGlass lint in CI.
- Added RISC-V ISA manual material for CV32A65X.

## Support

Maintained through the upstream OpenHW CVA6 repository.

## Verification

Release notes identify CI lint integration alongside architecture and MMU changes.
