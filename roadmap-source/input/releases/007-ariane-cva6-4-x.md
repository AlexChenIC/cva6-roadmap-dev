# Ariane/CVA6 4.x

## Summary

Historical upstream Ariane/CVA6 4.x release line covering the early public CVA6 baseline.
The roadmap portal keeps only one representative item from this historical line.

## Highlights

- Ariane 4.0.0 introduced early A-extension, floating-point, OpenPiton cache, FPGA, PLIC, and bootrom work.
- Ariane 4.1.2 added official FPU support, AXI 64-bit adaptation, atomics, and tandem simulation support.
- Ariane 4.2 added PMA/cacheability updates, AMO backoff, VCS fixes, tracer fixes, and privilege fixes.
