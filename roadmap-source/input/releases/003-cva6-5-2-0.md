# CVA6 5.2.0

## Summary

Real upstream CVA6 release with CV-X-IF 1.0.0 support, superscalar support, FPGA work, PMP/MMU decoupling, and tandem verification tooling.

## Highlights

- Added support for CV-X-IF 1.0.0.
- Added support for the Zbkb extension.
- Added superscalar support.
- Added Altera FPGA support and Spike tandem support.
- Made PMP independent from MMU and added LLVM toolchain build scripts.

## Support

Maintained through the upstream OpenHW CVA6 repository.

## Verification

Release notes include Spike tandem support and integration-related platform work.
