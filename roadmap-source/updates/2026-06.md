# June 2026 roadmap source update

This update introduces `roadmap-source/` as the public source of truth for the
CVA6 roadmap portal.

## What changed

- Official roadmap items now live as Markdown files in
  `roadmap-source/input/roadmap-items/`.
- Partner expectations and requested capabilities live as Markdown files in
  `roadmap-source/input/partner-needs/`.
- Release windows and organization metadata are maintained through Markdown
  input and generated into YAML for the website.
- Strategic pillars and project-level framing remain lightweight YAML because
  they change rarely.
- Website pages render from this folder at build time.

## Governance note

Partner needs are welcome as public input. They become official roadmap items only
after CVA6/OpenHW maintainers confirm owner, status, target window, release scope,
and evidence links.
